# AI based Chat App

A realtime AI-powered chat application built with the MERN Stack and Google Gemini API. This project demonstrates authentication, realtime messaging, and AI-assisted conversations in a modern full-stack application.

## 🚀 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI
- Google Gemini API

### Realtime
- Socket.IO

---

## ✨ Features

- User Authentication
- Realtime Chat
- AI Assistant
- Secure JWT Authentication
- Responsive UI
- Conversation History

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
cd ai-developer-chat
```

### Backend

```bash
cd backend
npm install
```

Create a `.env` file.

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GEMINI_API_KEY=your_gemini_api_key
CLIENT_URL=http://localhost:5173
```

Start the backend.

```bash
npm run dev
```

---

### Frontend

```bash
cd frontend
npm install
```

Start the frontend.

```bash
npm run dev
```
